# Структура команд CLI

Интерфейс спроектирован по принципу групп.

## 1. Глобальный поиск

Поиск по всей базе Московской биржи (Акции, Облигации, Фонды, Валюты).

Синтаксис:
```bash
moex search "ЗАПРОС"
```
Пример:
```bash
moex search "Яндекс"
moex search "SU26238"
```

## 2. Работа с акциями (share)

Группа команд для взаимодействия с рынком акций и ETF.
- `moex share info "ТИКЕР"` — Получить текущие данные об акции.
- `moex share find "ЗАПРОС"` — Поиск только среди акций.
- `moex share divs "ТИКЕР"` — Вывести историю и будущие дивиденды.

Примеры:
```bash
moex share info SBER
moex share divs LKOH
moex share find "Сбербанк"
```

## 3. Работа с облигациями (bond)

Группа команд для взаимодействия с рынком долга.
- `moex bond info "ТИКЕР"` — Получить текущие данные об облигации, цену, НКД и доходность.
- `moex bond find "ЗАПРОС"` — Поиск только среди облигаций.
- `moex bond coupons "ТИКЕР"` — Вывести историю и график будущих купонов.
- `moex bond amortizations "ТИКЕР"` — Вывести историю и график будущих выплат.

Примеры:
```bash
moex bond info RU000A10DS74
moex bond find "ОФЗ"
moex bond coupons SU26238RMFS4
moex bond amortizations RU000A10DS74
```
