# Документация по поиску (Search)
[← Вернуться к README](../README.md)
[← Полный пример кода](../examples/test_search.py)

Глобальный поиск позволяет находить финансовые инструменты на Московской бирже по различным параметрам: тикеру, краткому или полному названию, ISIN или регистрационному номеру.

Результатом поиска является список объектов модели Search.
Поля, возвращаемые Московской биржей

В таблице ниже приведено соответствие сырых полей MOEX ISS API и атрибутов в SDK `pymoex`.
Идентификаторы

Базовые параметры для точной идентификации бумаги.
## Идентификаторы
Базовые параметры для точной идентификации бумаги.


| Поле (API) | Атрибут в SDK | Тип в Python | Описание |
| --- | --- | --- | --- |
| `secid` | `sec_id` | `str` | Торговый код (тикер) инструмента |
| `shortname` | `short_name` | `str` | Краткое наименование ценной бумаги |
| `name` | `name` | `str` | Полное наименование инструмента |
| `isin` | `isin` | `str` | Международный идентификационный код |
| `regnumber` | `reg_number` | `str` | Регистрационный номер (обычно есть у акций и облигаций) |

## Классификация
Параметры, определяющие вид и группу финансового инструмента.
| Поле (API) | Атрибут в SDK | Тип в Python | Описание |
| --- | --- | --- | --- |
| type | type | str | Тип бумаги |
| group | group | str | Группа инструмент |

## Торговые данные
Информация о текущем статусе торгов инструментом.

| Поле (API) | Атрибут в SDK | Тип в Python | Описание |
| --- | --- | --- | --- |
| is_traded | is_traded | bool | Торгуется ли инструмент в данный момент на бирже |
| primary_boardid | primary_boardid | str | Главный режим торгов |
| marketprice_boardid | marketprice_boardid | str | Режим торгов, используемый для расчета рыночной цены |
|  |  |  |  |


## Эмитент (Компания)
Данные о юридическом лице, выпустившем ценную бумагу.
| Поле (API) | Атрибут в SDK | Тип в Python | Описание |
| --- | --- | --- | --- |
| emitent_id | emitent_id | int | Внутренний идентификатор эмитента на Московской бирже |
| emitent_title | emitent_title | str | Юридическое название компании-эмитента |
| emitent_inn | emitent_inn | str | ИНН компании-эмитента |
| emitent_okpo | emitent_okpo | str | ОКПО компании-эмитента |

## Пример использования в коде
```python
query = "Сбербанк"
#Поиск только среди акций
print(f"--- Ищем акции по запросу: {query} ---")
shares = await client.find(query, instrument_type="share")
        
for r in shares[:3]:
    print(r)
            
Поиск только среди облигаций
print(f"\n--- Ищем облигации по запросу: {query} ---")
bonds = await client.find(query, instrument_type="bond")
        
for r in bonds[:3]:
    print(r)
```
